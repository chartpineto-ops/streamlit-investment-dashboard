# IntelBridge Milestones 1–3 Release

Date: 2026-07-23

This document supersedes the earlier full-vertical-slice prototype note. The
active release is deliberately limited to foundation, research-run execution,
and connector ingestion. See
[MILESTONES_1_3.md](MILESTONES_1_3.md) for the current architecture, API,
security, validation, and operations record.

The legacy D1 tables for evidence, claims, insights, monitors, alerts, reports,
agents, and question history remain only for non-destructive migration
compatibility with the previous prototype database. No active route, UI
navigation, background job, or API in this release reads or produces those
later-milestone outputs.
